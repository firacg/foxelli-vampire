# Stealing the Vampire

English production-development presentation for the Foxelli AI Filmmaker project.

**Live site:** https://firacg.github.io/foxelli-vampire/

Includes character and expression sheets, environment studies, props and staging references, eight scene frame pools, English storyboards, exact video prompts, START/END keyframes and existing video tests.

WAN 3.0 was chosen for the project from the outset. This is a work-in-progress presentation, not the final submitted episode. S14, S20 and S37 still require a further pass.

Display previews are optimized for the web. PNG download links preserve the original selected files. The full English production pack is available from the release download linked on the page.

## Hosting

Static HTML and local media. Published with GitHub Pages from the root of `main`. No build system, API keys or external asset services are required.

Media and project materials are provided for presentation and review; no additional reuse license is granted here.
